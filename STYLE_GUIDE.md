# Style Guide

## Guiding Principles
- Favor explicit, concise code paths. Do not chase DRY abstractions; duplicate logic when it keeps the code compact and clear.
- Keep functions small and purpose-built; prefer short functions over large general helpers.

## Documentation
- Document every public-facing function or method with a JSDoc block describing purpose, parameters, and return value.
- Avoid inline comments; rely on descriptive names and structure so the code remains self-documenting.
